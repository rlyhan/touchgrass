# Recommendation Card

## Summary

Each recommendation card is given a different type (eg. Constructive, Active), field (eg. Music, Martial Arts), and estimated time. We need a different icon based on the value of the field.

## Requirements

- Each type must reflect the label, eg. Constructive could be a spanner, Artistic should be the palette
- Each field must reflect the label, eg. Music could be a guitar
- Estimated time should always be a clock icon
