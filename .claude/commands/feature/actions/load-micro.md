# Load Micro Action

1. Open current-feature.md and read the current feature context
2. Ask for the micro-feature name and its requirements
3. Update current-feature.md:
   - Change H1 to `# {micro-feature-name}`
   - Write micro-feature requirements under ## Requirements
   - Clear ## Notes
   - Leave ## Parent Branch empty (start-micro will populate this)
4. Confirm micro-feature loaded and show summary
